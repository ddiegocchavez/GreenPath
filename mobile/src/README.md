# mobile/src/

| Carpeta | Qué hace |
|---|---|
| `screens/` | Pantallas completas (una por archivo) |
| `navigation/` | Cómo se pasa de una pantalla a otra |
| `features/` | Lógica de cada función, separada por tema |
| `components/` | Piezas visuales reutilizables |
| `lib/` | Clientes y utilidades técnicas (Supabase, SQLite, fechas) |
| `theme/` | Colores, tipografía y espaciados |
| `types/` | Tipos compartidos, incluido el contrato de sincronización |
