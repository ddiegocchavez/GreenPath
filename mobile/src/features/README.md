# features/

Lógica separada por función. Cada carpeta es independiente.

| Carpeta | Qué hace |
|---|---|
| `auth/` | Registro, inicio y cierre de sesión |
| `usage/` | Permiso de acceso al uso y lectura de tiempos por app |
| `sync/` | Envío de resúmenes al servidor y cola de pendientes |
| `preferences/` | Presupuesto, esfuerzo, cambios dispuestos y tono |
| `recommendations/` | Filtrar y mostrar recomendaciones del catálogo |
| `events/` | Eventos (carne asada, fiesta) y sus productos |
| `progress/` | Elegidas, realizadas, puntos y estimaciones |
| `photos/` | Ampliación: foto + categoría manual |
