# docs/catalogo/

Criterios para el catálogo curado (sin IA):

- **Recomendaciones:** qué hacer, por qué podría reducir emisiones, datos y supuestos, esfuerzo y gasto.
- **Productos:** tienda, enlace verificado a mano, precio con fecha de consulta y presentación, criterio ambiental por categoría.

Los datos que carga la base viven en `supabase/seed/`.
