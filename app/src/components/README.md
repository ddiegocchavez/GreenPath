# components/ — Interfaz

- `ui.tsx` — encabezado, títulos, opciones e insignias P1–P4 / S1–S4.
- `pasos/Inicio.tsx` — nombre, ubicación, elegir lista o ticket.
- `pasos/Lista.tsx` — editor de despensa (también lo usa la revisión del ticket) y presupuesto.
- `pasos/Ticket.tsx` — foto → OCR → revisión → qué quieres hacer.
- `pasos/Prioridad.tsx` — precio, calidad o sustentabilidad.
- `pasos/Resultados.tsx` — recomendado, tiendas (menor↔mayor), combinaciones y detalle.
