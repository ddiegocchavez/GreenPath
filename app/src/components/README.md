# components/ — Interfaz

- `ui.tsx` — encabezado (botón para regresar, progreso, insignia PLUS, Mi valor y cerrar sesión), títulos, opciones e insignias de calidad (premium, superior, normal, estándar) y S1–S4.
- `onboarding/Encuesta.tsx` — encuesta de una vez: uso, personas, frecuencia, gasto, problemas y qué no cambiar.
- `onboarding/Propuesta.tsx` — diagnóstico, plan recomendado y Gratis vs Plus (demo).
- `pasos/Inicio.tsx` — nombre y ubicación (centrados) y elegir entre lista o ticket.
- `pasos/Lista.tsx` — editor de despensa (también lo usa la revisión del ticket, con la opción de cambiar producto) y presupuesto.
- `pasos/Ticket.tsx` — foto → OCR → revisión ("¿Qué es esto?" aprende) → qué quieres hacer.
- `pasos/Prioridad.tsx` — precio, calidad o sustentabilidad.
- `pasos/Resultados.tsx` — recomendado, preferencias aplicadas, lista habitual vs optimizada, alternativas, vista previa de Plus, guardar, tiendas de menor a mayor y combinaciones.
- `MiValor.tsx` — estimado vs comprobado vs demo, huella, historial, revisión del periodo, créditos, plan y tus datos.
