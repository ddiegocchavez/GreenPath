# supabase/

Backend en Supabase: base de datos, seguridad y funciones del servidor.

| Carpeta | Qué contiene |
|---|---|
| `migrations/` | Cambios de esquema en orden (tablas, RLS, funciones SQL) |
| `functions/` | Edge Functions (TypeScript/Deno) |
| `seed/` | Datos iniciales: catálogo y datos de demostración marcados `is_demo` |
| `tests/` | Pruebas SQL: RLS, idempotencia, que lo antiguo no sobrescriba |
